# roles/support_triage_agent/assessments/README.md

Candidates must complete 4 assessments. Each produces artifacts that can be graded.

A1) Triage Work Sample (ticket intake + classification)
A2) Evidence Correlation (logs/metrics snippets + timeline)
A3) Duplicate Detection (linking + confidence)
A4) Policy & Escalation Drill (redlines + escalation)

All artifacts must be generated with strict:
- No invented tool outputs
- Facts/Hypotheses/Next Steps sections
- JSON where requested
